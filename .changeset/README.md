# Changesets

This directory is managed by [Changesets](https://github.com/changesets/changesets). Run `pnpm changeset` to record a change before merging a PR that touches a published package's behavior (in this monorepo, that's `packages/cli`, published as `@team-monet/aart` — see ADR-18). Read the [full documentation](https://github.com/changesets/changesets/tree/main/docs) for more information.
